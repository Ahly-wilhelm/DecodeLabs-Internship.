# Project 4: Data Visualization

## Project Goal

The goal of this project is to create visual representations of e-commerce order data in order to communicate insights clearly. The project uses charts to summarize sales performance, customer payment behavior, referral sources, order status, and coupon usage.

## Dataset

The dataset contains **1,200 e-commerce orders** with columns such as order ID, date, product, quantity, unit price, total price, payment method, order status, referral source, and coupon usage.

## Tools Used

- Microsoft Excel dataset
- Python
- Pandas
- Matplotlib

## Visualizations Created

### 1. Revenue by Product
A horizontal bar chart was used to compare revenue generated by each product category. This visual helps identify the products contributing most to total revenue.

### 2. Monthly Revenue Trend
A line chart was used to show revenue movement over time. This is useful for identifying growth patterns, sales fluctuations, and possible seasonal changes.

### 3. Orders by Payment Method
A bar chart was used to compare how customers paid for their orders. This helps the business understand the most common payment channels.

### 4. Top Referral Sources
A bar chart was used to show which marketing or referral source produced the highest number of orders.

### 5. Order Status Breakdown
A bar chart was used to summarize order outcomes such as delivered, shipped, pending, returned, and cancelled orders.

### 6. Coupon Usage Share
A pie chart was used to show the proportion of orders where customers used a coupon.

## Key Insights

- The dataset contains **1,200 total orders**.
- Total revenue generated is **$1,264,761.96**.
- The average order value is **$1,053.97**.
- **Chair** generated the highest revenue with **$195,620.11**.
- **Instagram** was the top referral source with **259 orders**.
- **Credit Card** generated the highest payment-method revenue with **$263,847.63**.
- Coupon orders account for **891 orders**, generating **$942,360.55** in revenue.
- The highest revenue month was **2024-06**, with **$68,068.54** in revenue.
